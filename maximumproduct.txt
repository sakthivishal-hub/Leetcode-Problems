Intuition
To get the maximum product of two digits, we don't need to try all pairs — we just need the two largest digits in the number. So we scan the digits once and keep track of the largest (max1) and second largest (max2) as we go.

Approach
Initialize max1 and max2 to -inf so any real digit will replace them.
Extract digits from right to left using:
n % 10 → last digit
n //= 10 → remove last digit
For each digit:
If it's greater than max1 → demote max1 into max2, then set max1 = digit.
Otherwise → try to update max2 with max(max2, digit).
(The else branch also correctly handles duplicate digits, e.g. 99 → both max1 and max2 become 9.)
Return max1 * max2.
Dry run for n = 391:

digit	max1	max2
1	1	-inf
9	9	1
3	9	3
Result: 9 * 3 = 27 ✅

Complexity
Time complexity: 
O(log10n)
O(log10n) — one iteration per digit (number of digits = log₁₀n + 1). Effectively O(d), optimal since we must look at every digit.Space complexity: O(1)
O(1) — only two variables used, no extra storage.

Code:-
class Solution:
    def maxProduct(self, n: int) -> int:
        max1 = float("-inf")
        max2 = float("-inf")
        while n != 0:
            digit = n % 10
            if digit > max1:
                max2 = max1
                max1 = digit
            else:
                max2 = max(max2, digit)
            n //= 10
        return max1 * max2
