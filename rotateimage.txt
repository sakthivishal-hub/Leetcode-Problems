Intuition
Rotating a matrix 90° clockwise looks tricky at first, but there's a beautiful trick:
Transpose the matrix, then reverse each row → same as rotating 90° clockwise!

Doing it in-place saves extra space.

Approach
Transpose the matrix — swap matrix[i][j] with matrix[j][i] (flip along the main diagonal).
Only iterate j from i to n to avoid swapping twice.
Reverse each row — this flips the transposed matrix horizontally, giving the final 90° clockwise rotation.

Time complexity: 
O(n2)
O(n2)

Space complexity: 
O(1)
O(1)
In-place rotation — no extra matrix used.

class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        for i in range(len(matrix)):
            for j in range(i, len(matrix[0])):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
            matrix[i].reverse()
